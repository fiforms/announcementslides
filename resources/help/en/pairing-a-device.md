A Slide Announcer is a small device plugged into a church TV that shows your
church's slides automatically. A device belongs to a **church**, not to one
person, so it keeps working when volunteers change.

## Pair a device

1. Turn on the device. It shows a pairing screen.
2. In the site, open your church's **Slide Announcers** page and choose **Generate pairing code**.
3. Type the code into the device's pairing screen. The code expires after a short time; generate a new one if it runs out.

Once paired, the device appears in the list with its name, language and when it
last checked in. It checks in about once a minute, so changes you make here
reach the device within about a minute.

## Settings

- **Name:** how the device is listed.
- **Language:** filters which language-specific slides sync to this device. Leave it on the device's own default if you don't need to filter. See [Slide languages](help:slide-languages).

## Unpairing

Choose **Unpair this device** to disconnect it. It will need a new pairing code
to reconnect.

For feeding live video to a device, see [LAN video receiver](help:lan-video-receiver).
